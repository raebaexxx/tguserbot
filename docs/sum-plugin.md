# Плагин `sum`

Сводка по последним сообщениям в чате, где вы написали команду.

```
/ub sum          — последние 10 сообщений
/ub sum 25       — последние 25 (максимум 50)
/ub sum 10 media — вместе с голосовыми и кружками
/ub sum text     — только текст
```

Команда работает в любом чате, где бот состоит, — команды `/ub` владельцу, а не
только в личных.

## ⚠️ Приватность: медиа выключено по умолчанию

**Сводка отправляет переписку Google.** Это чужие сообщения, и владелец бота
соглашался на это за себя, но не за остальных. Поэтому:

* `include_media = false` — по умолчанию. Текст уходит, голосовые и кружки нет.
* Включается осознанно, в `<data_dir>/plugin-config.toml`:

```toml
[sum]
include_media = true
```

Когда медиа выключено, но в выбранных сообщениях были вложения, плагин **говорит
об этом** в ответе. Молча пропущенное голосовое выглядело бы как забытое.

## Что понимается

Тип вложения определяется по форме, которую Telegram кладёт в сообщение, и mime
объявляется тот, который принимает Gemini. Каждый проверен на живой модели
настоящим сообщением из чатов бота:

| Что | Формат | mime |
|---|---|---|
| Голосовое | OGG/Opus | `audio/ogg` |
| Кружок | MP4 | `video/mp4` |
| Фото | JPEG | `image/jpeg` |
| Аудио, видео, документы | по расширению | `audio/*`, `video/*`, `image/*` |

Формат, который определить не удалось, **пропускается с указанием причины** —
не угадывается: неверный mime даёт ошибку модели про файл, которого в сводке
даже не упоминалось.

## Лимиты

| Параметр | По умолчанию | Зачем |
|---|---|---|
| `message_count` | 10 | сколько сообщений |
| `max_message_count` | 50 | потолок для числа из команды |
| `max_media_bytes` | 4 МБ | на один файл |
| `max_total_media_bytes` | 15 МБ | на всю подборку |
| `max_transcript_chars` | 24000 | длина транскрипта |
| `timeout_seconds` | 180 | дольше, чем у `ai`: несёт транскрипт и медиа |

При исчерпании бюджета **первыми выпадают самые старые вложения** — свежие обычно
и есть то, о чём спрашивали. Всё, что не попало в запрос, перечисляется в ответе.

Транскрипт обрезается тоже с конца: у длинной переписки хвост интереснее начала.

Если квота модели на бесплатном тарифе исчерпана, плагин переходит на следующую
из `model_fallbacks` и пишет об этом строкой под сводкой — суточный лимит
считается на каждую модель отдельно, поэтому запасная модель обычно отвечает.
Подробности в [ai-plugin.md](ai-plugin.md#когда-квота-кончилась).

## Формат ответа

```
Сводка по последним 10 сообщениям:

<описание темы>
• ...
• ...
...

Не учтено:
• медиа не отправляются (include_media = false), вложений пропущено: 3
• голосовое больше лимита
```

Заголовок «Не учтено» появляется, только когда есть что сказать. Сводка,
которая тихо игнорирует половину разговора, хуже той, что признаётся в этом.

## Ответы модели пересобираются

У голосового сообщения нет текста, поэтому в транскрипте на его месте стоит
`(голосовое)`. Модель не может понять, какое вложение к какой строке относится, и
ей сказано не выдумывать соответствие, а признать неопределённость.
